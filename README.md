# CampusMind — AI-Powered Campus Digital Twin

> **One-command demo. Works 100% offline.**

CampusMind is a campus energy and resource management system that combines real-time building simulation, multi-agent AI negotiation, and a convex optimisation solver to shave peak loads, cut costs, and reduce carbon — while keeping comfort floors non-negotiable.

## ⚡ Quick Start

```powershell
# Clone and enter
cd c:\Users\prath\Documents\kaushal\hackathon

# One command — installs everything, seeds data, trains model, starts both servers
make demo
```

Then open **http://localhost:5173** in your browser.

> **Offline demo:** Set `LLM_MODE=mock` (the default) for deterministic, offline operation. The demo never touches the internet.

## 🎛 Demo Walk-through

1. **Normal Day** — Both twins run in lockstep. Managed twin shows marginal savings from scheduling (pump off-peak, lighting dimming).

2. **Heatwave Scenario** — Click **Heatwave +8°C** in the Chaos Panel. HVAC load spikes → grid import approaches cap → negotiation auto-triggers.

3. **Negotiation** — Watch the Negotiation Feed:
   - GridAgent broadcasts an Ask (shed 68 kW over 2 h)
   - ZoneAgents respond with Offers
   - cvxpy Solver verifies and allocates
   - Deal card appears → one click to approve (or enable Auto-Approve)

4. **Grid Outage** — Click **Grid Outage (60%)**. Cap drops to ~510 kW. Urgent outage negotiation triggers immediately.

5. **Tank Leak** — Click **Tank Leak**. Anomaly detector fires, water isolation deal proposed.

6. **Phantom Load** — Click **Phantom Load**. 35 kW ghost load detected in Labs; waste-fix deal eliminates it.

## ⚙️ Configuration

Copy `.env.example` to `.env` and adjust as needed:

| Variable | Default | Description |
|---|---|---|
| `LLM_MODE` | `mock` | `mock` = offline deterministic; `live` = Gemini API |
| `GEMINI_API_KEY` | _(empty)_ | Required only when `LLM_MODE=live` |
| `SEED` | `42` | RNG seed for deterministic replay |
| `GRID_CAP_KW` | `850` | Campus grid import cap |
| `SOLAR_PEAK_KW` | `250` | Rooftop solar peak capacity |
| `AUTO_APPROVE` | `false` | Auto-approve all deals without human click |
| `SIM_SPEED_SECONDS_PER_SIM_HOUR` | `3` | Sim speed (3s real = 1h simulated) |
